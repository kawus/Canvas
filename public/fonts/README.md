# Fonts for font cards

Regular (400) Latin files of free typefaces, all under the SIL Open Font License 1.1
(https://openfontlicense.org), downloaded from Fontsource by `node scripts/fetch-fonts.cjs`.
The list lives in `src/fonts.ts`. Each font is © its designers; the licence allows
use, sharing and embedding, including in commercial products, but not selling the fonts on their own.
