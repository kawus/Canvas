## Tools

| Key | Tool |
| --- | --- |
| <kbd>V</kbd> | Select |
| <kbd>H</kbd> or hold <kbd>Space</kbd> | Hand (move around) |
| <kbd>P</kbd> | Pen |
| <kbd>E</kbd> | Eraser |
| <kbd>R</kbd> / <kbd>O</kbd> | Rectangle / Ellipse |
| <kbd>A</kbd> / <kbd>L</kbd> | Arrow / Line |
| <kbd>N</kbd> | Sticky note |
| <kbd>T</kbd> | Text (or double-click the board) |
| <kbd>I</kbd> | Insert image |

## Editing

| Key | Action |
| --- | --- |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | Undo / Redo |
| <kbd>⌘C</kbd> / <kbd>⌘V</kbd> | Copy / Paste |
| <kbd>⌘D</kbd> | Duplicate |
| <kbd>⌥</kbd> + drag | Duplicate while dragging |
| <kbd>⌫</kbd> | Delete |
| <kbd>[</kbd> / <kbd>]</kbd> | Send to back / Bring to front |
| <kbd>Enter</kbd> | Edit the selected text or label |
| Arrow keys | Nudge the selection |
| <kbd>⌘</kbd> while dragging | Don't snap |

## Aligning

| Key | Action |
| --- | --- |
| <kbd>⌥A</kbd> / <kbd>⌥H</kbd> / <kbd>⌥D</kbd> | Align left / centre / right |
| <kbd>⌥W</kbd> / <kbd>⌥V</kbd> / <kbd>⌥S</kbd> | Align top / middle / bottom |
| <kbd>⇧⌥H</kbd> / <kbd>⇧⌥V</kbd> | Space evenly across / down |

## View

| Key | Action |
| --- | --- |
| <kbd>⌘</kbd> + scroll, or pinch | Zoom |
| <kbd>⇧1</kbd> | Zoom to fit everything |
| <kbd>⇧0</kbd> | Zoom to 100% |
| <kbd>?</kbd> | Show the shortcuts in Canvas |

On Windows and Linux, use <kbd>Ctrl</kbd> instead of <kbd>⌘</kbd> and <kbd>Alt</kbd> instead of <kbd>⌥</kbd>.

> In Canvas, press <kbd>?</kbd> or tap the **?** button in the bottom-right corner to see these shortcuts any time — shown with the right keys for your computer.
