## The launcher

Press <kbd>⌘K</kbd> (<kbd>Ctrl+K</kbd> on Windows), or <kbd>/</kbd>, to open the launcher: one quiet search field for everything Canvas does. Type a few letters (“sti” for a sticky note, “pre” to present, “font”, “place”, the name of another board) and press <kbd>Enter</kbd>. Use <kbd>↑</kbd> <kbd>↓</kbd> to choose and <kbd>Esc</kbd> to close.

It also understands what you type: paste a link and <kbd>Enter</kbd> adds it (videos and music become players), type a colour code like `#c56b3e` for a swatch, and anything else becomes a sticky note.

## Tools

| Key | Tool |
| --- | --- |
| <kbd>V</kbd> | Select |
| <kbd>H</kbd> or hold <kbd>Space</kbd> | Hand (move around) |
| <kbd>P</kbd> | Pen |
| <kbd>E</kbd> | Eraser |
| <kbd>R</kbd> / <kbd>O</kbd> | Rectangle / Ellipse |
| <kbd>A</kbd> / <kbd>L</kbd> | Arrow / Line |
| <kbd>N</kbd> | Sticky note (then just start typing) |
| <kbd>T</kbd> | Text (or double-click the board) |
| <kbd>I</kbd> | Insert image |

## Editing

| Key | Action |
| --- | --- |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | Undo / Redo |
| <kbd>⌘C</kbd> / <kbd>⌘V</kbd> | Copy / Paste |
| <kbd>⌘D</kbd> | Duplicate |
| <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> | Group / Ungroup |
| <kbd>⌥</kbd> + drag | Duplicate while dragging |
| <kbd>⌫</kbd> | Delete |
| <kbd>[</kbd> / <kbd>]</kbd> | Send to back / Bring to front |
| <kbd>Enter</kbd> | Edit the selected text or label, or crop the selected image |
| <kbd>Tab</kbd> (while writing a sticky note) | Start the next note beside it, joined by a line |
| Arrow keys | Nudge the selection |
| <kbd>⌘</kbd> while dragging | Don't snap |

## Aligning

| Key | Action |
| --- | --- |
| <kbd>⌥A</kbd> / <kbd>⌥H</kbd> / <kbd>⌥D</kbd> | Align left / centre / right |
| <kbd>⌥W</kbd> / <kbd>⌥V</kbd> / <kbd>⌥S</kbd> | Align top / middle / bottom |
| <kbd>⇧⌥H</kbd> / <kbd>⇧⌥V</kbd> | Space evenly across / down |

## View

| Key | Action |
| --- | --- |
| <kbd>⌘</kbd> + scroll, or pinch | Zoom |
| <kbd>⇧1</kbd> | Zoom to fit everything |
| <kbd>⇧0</kbd> | Zoom to 100% |
| <kbd>F</kbd> | Focus mode: hide everything but the board (<kbd>F</kbd> or <kbd>Esc</kbd> to bring the tools back) |
| <kbd>?</kbd> | Show the shortcuts in Canvas |

## Presenting

| Key | Action |
| --- | --- |
| <kbd>→</kbd> or <kbd>Space</kbd> | Next slide |
| <kbd>←</kbd> | Previous slide |
| <kbd>O</kbd> | Overview of the whole board |
| <kbd>Esc</kbd> | Stop presenting |

On Windows and Linux, use <kbd>Ctrl</kbd> instead of <kbd>⌘</kbd> and <kbd>Alt</kbd> instead of <kbd>⌥</kbd>.

> In Canvas, press <kbd>?</kbd> or tap the **?** button next to the zoom controls to see these shortcuts any time — shown with the right keys for your computer.
